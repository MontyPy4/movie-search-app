# Movie Search Application / Приложение для поиска фильмов

Интерактивное консольное приложение для поиска фильмов по базе данных sakila MySQL с логированием запросов в MongoDB.

## 🎯 Функционал

### 1. Поиск фильмов
- **По ключевому слову** - поиск по названию фильма с пагинацией (10 результатов на странице)
- **По жанру и диапазону лет** - расширенный поиск с отображением доступных жанров и диапазона лет в базе

### 2. Логирование запросов
Все поисковые запросы автоматически сохраняются в MongoDB с информацией:
- Временная метка (timestamp)
- Тип запроса (search_type): `keyword` или `genre__years_range`
- Параметры поиска (params)
- Количество найденных результатов (results_count)

### 3. Статистика
- **5 самых популярных запросов** - по частоте выполнения
- **5 последних уникальных запросов** - в хронологическом порядке
- **Общая статистика** - информация о всех выполненных запросах

## 📋 Требования

- Python 3.8+
- MySQL (база данных sakila)
- MongoDB

## 🔧 Модули приложения

### config.py
Управление конфигурацией:
- Настройка подключения к MySQL и MongoDB
- Параметры поиска (размер страницы, лимит статистики)
- Загрузка переменных из файла `.env`

### mysql_connector.py
Функции работы с базой данных sakila:
- `get_mysql_connection()` - подключение к MySQL
- `get_all_genres()` - получение списка жанров
- `get_year_range()` - получение диапазона лет
- `search_by_keyword()` - поиск по названию с пагинацией
- `search_by_genre_and_years()` - поиск по жанру и годам с пагинацией

### log_writer.py
Запись поисковых запросов в MongoDB:
- `log_search_query()` - запись запроса в БД
- `log_keyword_search()` - запись поиска по ключевому слову
- `log_genre_years_search()` - запись поиска по жанру/годам

### log_stats.py
Получение аналитики из MongoDB:
- `get_popular_searches()` - топ-5 популярных запросов
- `get_latest_searches()` - топ-5 последних уникальных запросов
- `get_total_searches_count()` - общее количество запросов

### formatter.py
Красивый вывод результатов в консоль:
- Таблицы с фильмами и информацией о пагинации
- Список жанров в многоколонном формате
- Статистика запросов в структурированном виде
- Заголовки и разделители

### main.py
Интерактивное консольное меню:
- Главное меню с опциями поиска и просмотра статистики
- Обработка ввода пользователя
- Поддержка пагинации для результатов поиска
- Обработка ошибок и исключений

## 📊 Примеры SQL запросов

### Поиск по ключевому слову:
```sql
SELECT film_id, title, release_year, rating, length
FROM film
WHERE title LIKE %keyword%
ORDER BY title
LIMIT 10 OFFSET 0
```

### Поиск по жанру и годам:
```sql
SELECT DISTINCT f.film_id, f.title, f.release_year, f.rating, f.length
FROM film f
JOIN film_category fc ON f.film_id = fc.film_id
JOIN category c ON fc.category_id = c.category_id
WHERE c.name = 'Action' 
AND f.release_year BETWEEN 2005 AND 2012
ORDER BY f.release_year DESC, f.title
LIMIT 10 OFFSET 0
```
