# Презентация проекта: Приложение для поиска фильмов

## 📋 Краткое описание

Интерактивное консольное приложение на Python для поиска фильмов по базе данных sakila MySQL с  логированием запросов в MongoDB и отображением статистики.

## 🎯 Что реализовано в проекте

### 1. Функционал поиска ✓
- **Поиск по ключевому слову** с пагинацией (10 результатов на странице)
- **Поиск по жанру и диапазону лет** с автоматическим определением доступных жанров и лет
- **Пагинация** для больших наборов результатов (10 результатов на странице)

### 2. Логирование в MongoDB ✓
- **Автоматическое логирование** каждого поискового запроса
- **Структурированные данные**:
  - timestamp - время запроса
  - search_type - тип поиска (keyword или genre__years_range)
  - params - параметры поиска
  - results_count - количество найденных результатов
- **Хранение в существующей коллекции** MongoDB

### 3. Аналитика и статистика ✓
- **5 самых популярных запросов** по частоте выполнения
- **5 последних уникальных запросов** в хронологическом порядке:
Хронологический порядок достигается через {"$sort": {"timestamp": -1}} — документы сортируются от новых к старым.
- **Общая статистика** - количество всех выполненных запросов
- **Агрегация данных** через MongoDB pipeline

### 4. Пользовательский интерфейс ✓

- **Интерактивное консольное меню** с рекурсивной обработкой
- **Красивое форматирование** результатов в виде таблиц
- **Информативные сообщения** об ошибках
- **Поддержка пагинации** с навигацией стрелками

### 5. Качество кода ✓
-  **PEP8 соответствие** - проверено и исправлено через flake8
- **Модульная архитектура** - разделение на 6 основных модулей
- **Документация** - docstrings для всех функций
- **Обработка ошибок** - try-except блоки, валидация входных данных

### Примеры SQL запросов

#### Поиск по ключевому слову:
```sql
SELECT film_id, title, release_year, rating, length
FROM film
WHERE title LIKE '%keyword%'
ORDER BY title
LIMIT 10 OFFSET 0;
```

#### Получение жанров:
```sql
SELECT DISTINCT name 
FROM category 
ORDER BY name;
```

#### Поиск по жанру и годам:
```sql
SELECT DISTINCT f.film_id, f.title, f.release_year, f.rating, f.length
FROM film f
JOIN film_category fc ON f.film_id = fc.film_id
JOIN category c ON fc.category_id = c.category_id
WHERE c.name = 'Action' 
AND f.release_year BETWEEN 2005 AND 2012
ORDER BY f.release_year DESC, f.title
LIMIT 10 OFFSET 0;
```

## 😎 Сложности и решения

### Сложность 1: Управление подключениями к двум БД
**Проблема:** Необходимо работать одновременно с MySQL и MongoDB

**Решение:** 
- Создали отдельные модули `mysql_connector.py` и `log_writer.py`
- Используем контекстные менеджеры для автоматического закрытия соединений
-  Централизованная обработка ошибок подключения

### Сложность 2: Пагинация результатов
**Проблема:** Результаты поиска могут быть большими (сотни фильмов)

**Решение:**
- Реализована пагинация на уровне SQL запросов (LIMIT + OFFSET)
- Интерактивное меню с вопросом "показать следующие 10?"
- Отслеживание текущей страницы и общего количества результатов

### Сложность 3: Поиск по жанру (JOIN таблиц)
**Проблема:** Информация о жанрах хранится в отдельной таблице

**Решение:**
- Используем JOIN между таблицами film, film_category и category
- DISTINCT для избежания дубликатов при нескольких жанрах у одного фильма
- Оптимизированный запрос с правильными индексами

### Сложность 4: Безопасность конфиденциальных данных
**Проблема:** Пароли БД не должны храниться в коде

**Решение:**
- Использование переменных окружения через `python-dotenv`
- Файл `.env` в `.gitignore`
- Пример конфигурации в `.env.example`
- Документация по безопасности в README
